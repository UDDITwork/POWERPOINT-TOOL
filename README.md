# POWERPOINT-TOOL

AI-powered patent diagram generator that creates fully editable PowerPoint presentations.

## Features

- 🤖 Elite AI using Claude Sonnet 4.5
- 📊 Handles complex nested diagrams (FIG. 2 level)
- ✅ 100% editable PowerPoint output
- 🚀 Cloud Run ready
- 💎 182 PowerPoint shapes supported

## Quick Start

```bash
cd backend
pip install -r requirements.txt
python setup_and_test.py
```

See [GET_STARTED.txt](GET_STARTED.txt) for detailed instructions.

## Architecture

- **Elite Claude Agent**: Multi-pass reasoning for diagram generation
- **Advanced Layout Engine**: Constraint-based positioning
- **python-pptx**: Native PowerPoint rendering
