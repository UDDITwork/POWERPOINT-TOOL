================================================================================
DEPLOYMENT STEPS
================================================================================

1. Push to GitHub (already done):
   Repository: https://github.com/UDDITwork/POWERPOINT-TOOL

2. Go to Cloud Run Console:
   https://console.cloud.google.com/run

3. CREATE SERVICE > "Continuously deploy from a repository"

4. Connect GitHub:
   - Repository: UDDITwork/POWERPOINT-TOOL
   - Branch: main
   - Build type: Buildpacks
   - Source: /backend

5. Cloud Build will automatically:
   - Detect Python from runtime.txt
   - Install deps from requirements.txt
   - Start app using Procfile command

================================================================================
HOW IT WORKS
================================================================================

Procfile tells Cloud Run:
  web: uvicorn main:app --host 0.0.0.0 --port $PORT

runtime.txt tells Cloud Build:
  python-3.11.14

requirements.txt:
  All pure Python packages (no C++ compilation)

.gcloudignore:
  Excludes test files, .env, venv from deployment
