# Sample Prompts for AI Patent Diagram Generator

## Simple Flowcharts

### Basic 3-Step Process
Create a flowchart with 3 steps: Input (100), Processing (200), Output (300). Connect them vertically with arrows.

### Data Processing Method
Generate a patent method flowchart showing:
- Start: Receive sensor data (100)
- Process: Validate data (200)
- Decision: Is data valid? (210)
- If yes: Store in database (300)
- If no: Request new data (220)
- End: Complete (400)

### Machine Learning Pipeline
Create a flowchart for an ML system:
- Step 100: Collect training data
- Step 200: Preprocess and clean data
- Step 300: Train neural network model
- Step 400: Validate model accuracy
- Step 500: Deploy model to production
Add decision point after validation: if accuracy > 95%, deploy; else, retrain

## Refinement Examples
(Use these after generating initial diagrams)

### Size Adjustments
- "Make the processing block 50% wider"
- "Increase the size of the server box to 4 inches wide"
- "Make all client rectangles smaller, about 1.5 inches"

### Layout Changes
- "Move the database to the right side"
- "Arrange the three clients horizontally instead of vertically"
- "Center all elements on the slide"

### Content Modifications
- "Add a new decision diamond between steps 2 and 3 asking 'Is valid?'"
- "Change the label on box 100 to 'User Input Module (100)'"
- "Add a dotted arrow from step 4 back to step 1 for error handling"

### Styling
- "Change the color of the server box to blue"
- "Make all arrows thicker, width 2.5 points"
- "Use dashed lines for all optional connections"

## Tips for Best Results

1. **Be Specific**: Include reference numbers (100, 200, etc.)
2. **Describe Layout**: "vertical flow", "horizontal arrangement", "centered"
3. **Name Connections**: "bidirectional arrows", "one-way data flow"
4. **Include Counts**: "3 clients", "5 sensors" (not "multiple" or "several")
5. **Use Patent Language**: "receiving, by processor", "transmitting to device"
6. **Specify Shapes**: "rectangle", "diamond for decision", "oval for terminator"

## Bad vs Good Prompts

❌ Bad: "Create a diagram for my system"
✅ Good: "Create a block diagram showing a server (100) connected to 3 databases (110, 120, 130) with bidirectional arrows"

❌ Bad: "Make a flowchart with some steps"
✅ Good: "Create a vertical flowchart with 4 process blocks: Input (100), Validate (200), Process (300), Output (400), connected with arrows"

❌ Bad: "Add more stuff to the diagram"
✅ Good: "Add a new rectangle labeled 'Cache Layer (150)' between the API Gateway and Database, with arrows pointing both directions"
