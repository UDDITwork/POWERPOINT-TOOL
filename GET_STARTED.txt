USAGE EXAMPLE (Python)
================================================================================

from diagram_engine.unified_pipeline import PatentDiagramPipeline

pipeline = PatentDiagramPipeline(
    anthropic_api_key="your-key-here"
)

# Generate FIG. 2 style diagram
pipeline.generate(
    prompt="""
    Create a computer system with:
    - Computer System (202) containing:
      - System Metrics (210A)
      - Time Series Model (212) containing:
        - Embeddings (212A) with 214A and 214B
    """,
    output_path="my_diagram.pptx",
    quality="high"  # Use multi-pass for best quality
)

# Result: my_diagram.pptx (fully editable!)

================================================================================
TROUBLESHOOTING
================================================================================

Error: "ANTHROPIC_API_KEY not found"
→ Check backend/.env file has your API key

Error: "Module not found"
→ Run: pip install -r requirements.txt

Error: "API connection failed"
→ Check internet connection and API key validity

Diagrams look wrong in PowerPoint
→ Make sure you're using PowerPoint (not Google Slides)
→ All shapes should be individually selectable
